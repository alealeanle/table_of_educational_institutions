## Команды

### **Сборка проекта**

```sh
yarn build
```

Собирает проект в папку `dist`:

- Очищает старые файлы
- Компилирует Vue-компоненты
- Копирует статические файлы (`index.html`, `assets`, `stubs`)

### **Запуск разработки**

```sh
yarn dev
```

Запускает локальный сервер с **hot-reload** на порту `3000`.
При изменении файлов сборка обновляется автоматически.
